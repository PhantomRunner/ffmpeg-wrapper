# Локальная сборка MediaWrapper

Скачайте проект через Git и откройте терминал в корне клона. Для первой сборки нужен интернет. Инструменты и пакеты загружаются автоматически.

## Linux x64

Установите Git и Docker. Убедитесь, что `docker info` отрабатывает из вашей учётной записи. Версию Python и остальные зависимости подготовит контейнер.

```bash
./build.sh
```

AppImage, переносимый архив `.tar.gz` и журналы появятся в новом каталоге внутри `dist/builds/linux-x86_64/`.

## Windows x64

Установите Git и Python 3.11 x64 с Python Launcher. Команда `py -3.11 --version` должна находить установленный Python. Добавьте FFmpeg и FFprobe в `PATH` и проверьте их командами `ffmpeg -version` и `ffprobe -version`.

```powershell
.\build.cmd
```

Переносимый ZIP, установщик `.exe` и журналы появятся в новом каталоге внутри `dist/builds/windows-x86_64/`. Сборка проверяет приложение из распакованного ZIP. Для проверки установки и удаления используйте `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1` на чистой Windows-машине или в виртуальной машине.

## Повторная сборка и диагностика

Снова выполните команду вашей платформы. Терминал покажет путь к новому каталогу. Контрольные суммы лежат рядом с пакетами, подробности отдельных этапов — в `reports/`. При запуске самого MediaWrapper нужен доступ к FFmpeg и FFprobe.
